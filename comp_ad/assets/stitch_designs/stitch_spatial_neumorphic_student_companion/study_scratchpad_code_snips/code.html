Local Llama-3B Micro Summary (Offline):

TIM2 ISR releases binary semaphore to notify non-blocking RTOS consumer thread without latency jitter.

Context Note

Prioritize deterministic response over thread throughput. Interrupt handlers (ISRs) must strictly refrain from allocating dynamic heap or blocking mutex queries. Keep ISR length < 12us.
